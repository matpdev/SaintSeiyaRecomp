# disc/

Put `SLES_541.62` here, copied from your own disc of **Saint Seiya: The Hades** (Europe, SLES-54162), or
`SLPS_257.44` from the Japanese release (SLPS-25744; SHA-1 in `config/jp/SLPS_257.44.sha1`): `tools/disc.py`
writes the right one.
Nothing from the game is committed: this folder is ignored by git except this file.

Expected SHA-1 (`config/SLES_541.62.sha1`): `7ba6b0a1c05a94f28452840fcb73c204e46e79e6`.

The Brazilian fan translation is a different build, compressed with SjCRUNCH v0.3; it does not match.
